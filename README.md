# kas'Jam models

Downloaded by the app the first time someone asks for every bass note of a song.

- `vocals/drums/bass/other.fp16.onnx`: Spleeter 4 stems (Deezer, MIT) as ONNX, from https://huggingface.co/Best-Practice/spleeter-4stems-onnx (Apache-2.0).
- `nmp.onnx`: Basic Pitch (Spotify, Apache-2.0), https://github.com/spotify/basic-pitch
